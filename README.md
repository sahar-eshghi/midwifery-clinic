# قالب وب‌سایت کلینیک مامایی

## ساختار
- `index.html` صفحه اصلی
- `services/index.html` صفحه خدمات
- `courses/index.html` صفحه دوره‌ها
- `blog/index.html` صفحه وبلاگ
- `assets/css/style.css` استایل اصلی
- `assets/js/main.js` تعاملات و انیمیشن‌ها
- `assets/images/` تصاویر placeholder

## اجرا
پروژه بدون build tool اجرا می‌شود. فایل `index.html` را با مرورگر باز کنید.

## نکات
- متن‌ها و تصاویر عمداً به‌صورت جایگاه آماده هستند.
- برای اتصال فرم تماس به بک‌اند یا سرویس فرم، `action` فرم را تنظیم کنید.
- برای سئوی نهایی، دامنه واقعی در canonical قرار داده شود و sitemap/robots.txt روی هاست تنظیم گردد.
